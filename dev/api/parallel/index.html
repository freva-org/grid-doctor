Parallel writes¶

Functions and data classes for writing a pyramid with many independent workers, for example as an HPC array job. The workflow is

  1. init_pyramid_store creates empty level stores and returns a PyramidManifest with one WriteTask per unit of work,
  2. every worker calls write_pyramid_task for its task,
  3. check_pyramid_store reports whether all tasks finished.

The Parallel writes recipe explains the design, the manifest format and a complete reflow workflow.

init_pyramid_store(pyramid: dict[int, xr.Dataset], path: str, s3_options: S3Options | None = None, *, zarr_format: Literal[2, 3] = 2, encoding: PyramidEncoding | None = None, write_coords: bool | Literal['auto'] = 'auto', materialise: list[str] | None = None, structure: Literal['multiscales'], split: Mapping[str, int] | None = None, variables_per_task: int | None = None, if_exists: IfExists = 'error') -> None

Create empty pyramid stores and plan the work to fill them.

This is step one of a fan-out write. It writes, for every level, "<path>/level_<level>.zarr" with all metadata, encodings and coordinates, but none of the (lazy) data variables, and returns a PyramidManifest that splits the remaining work into independent WriteTask units. Hand each task to one worker, which calls write_pyramid_task; afterwards check_pyramid_store tells whether everything was written. The manifest is also stored as "<path>/_grid_doctor/manifest.json".

No data is computed (apart from coordinates and materialise), so the init is cheap even for stores with hundreds of thousands of chunks. The pyramid only needs the right shapes, dtypes, chunks and attributes; it can be built lazily from the full source.

What happens when path already holds a pyramid is controlled by if_exists; by default the init refuses, so a second run cannot destroy the stores of a first one by accident.

Whether to materialise the cell/latitude/longitude coordinate arrays in the store. HEALPix coordinates are a pure function of the cell index, and above roughly level 10 the arrays dwarf regional payloads (hundreds of GB at level 16, and they are never fill values, so chunk elision cannot help). "auto" (default) writes coordinates for levels up to :data:WRITE_COORDS_MAX_LEVEL and omits them above; True / False force either behaviour for all levels. Coordinate- less stores keep the crs grid mapping, are marked as having implicit coordinates (see HealpixMetadata), and are meant to be accessed through the region selectors (select_bbox, select_cells), which reconstruct coordinates for exactly the cells they return.

Data variables to compute and write completely during the init, e.g. small static fields. They are not part of any task.

"flat" (default) writes one store per level, "<path>/level_<level>.zarr", and plans the fan-out tasks. "multiscales" writes the template of a single datatree store at path (one group per level) and returns None: fan-out tasks are not supported for it yet, so split, variables_per_task and if_exists="resume" are rejected, and an existing store at path is overwritten. Fill it with save_pyramid and structure="multiscales".

 'flat'
split Mapping[str, int] | None

Task size per dimension in index units, e.g. {"time": 24} for tasks of 24 time steps. Sizes are rounded up to a multiple of the zarr chunk (or shard) size along that dimension, taken over all variables and levels, so no two tasks ever write to the same chunk. Several dimensions give the cartesian product of their regions. Splitting along cell is not supported. None (default) plans one task per group of variables, covering the whole store.

 None
variables_per_task int | None

Maximum number of variables per task. None (default) keeps all variables that share split dimensions and levels in one task, so the regridding they share is computed once per region.

 None
if_exists IfExists

What to do if path already has a manifest, level stores, or the remains of an interrupted init:

  • "error" (default): raise StoreExistsError.
  • "resume": if the stored manifest was planned exactly as this call would plan it (same path, levels, array layouts, split and tasks), return it unchanged, with its manifest_id, and write nothing. Tasks that already finished keep their markers, so re-submitting a conversion after a time-out only redoes the missing tasks. Raises StoreExistsError listing the differences otherwise, or if there is no readable manifest to resume (e.g. the previous init was killed). Without anything at path it initialises normally.
  • "overwrite": re-initialise. All data is discarded, the result gets a new manifest_id, and tasks and markers of the previous manifest become invalid; workers still running for it fail with StaleTaskError. Only overwrite when no worker of a previous run may still be writing: grid-doctor does not lock the store, and a worker that is already writing can put its data into the new stores before it notices.
 'error'

def init_pyramid_store(
    pyramid: dict[int, xr.Dataset],
    path: str,
    s3_options: S3Options | None = None,
    *,
    zarr_format: Literal[2, 3] = 2,
    encoding: PyramidEncoding | None = None,
    write_coords: bool | Literal["auto"] = "auto",
    materialise: list[str] | None = None,
    structure: Literal["flat", "multiscales"] = "flat",
    split: Mapping[str, int] | None = None,
    variables_per_task: int | None = None,
    if_exists: IfExists = "error",
) -> PyramidManifest | None:
    """Create empty pyramid stores and plan the work to fill them.

    This is step one of a fan-out write.  It writes, for every level,
    ``"<path>/level_<level>.zarr"`` with all metadata, encodings and
    coordinates, but none of the (lazy) data variables, and returns a
    [`PyramidManifest`][grid_doctor.PyramidManifest] that splits the
    remaining work into independent
    [`WriteTask`][grid_doctor.WriteTask] units.  Hand each task to one
    worker, which calls
    [`write_pyramid_task`][grid_doctor.write_pyramid_task]; afterwards
    [`check_pyramid_store`][grid_doctor.check_pyramid_store] tells
    whether everything was written.  The manifest is also stored as
    ``"<path>/_grid_doctor/manifest.json"``.

    No data is computed (apart from coordinates and *materialise*), so
    the init is cheap even for stores with hundreds of thousands of
    chunks.  The pyramid only needs the right shapes, dtypes, chunks and
    attributes; it can be built lazily from the full source.

    What happens when *path* already holds a pyramid is controlled by
    *if_exists*; by default the init refuses, so a second run cannot
    destroy the stores of a first one by accident.

    Parameters
    ----------
    pyramid:
        Mapping of HEALPix level to dataset, typically the lazy result
        of [`create_healpix_pyramid`][grid_doctor.create_healpix_pyramid].
    path:
        Target prefix.  An ``"s3://bucket/pyramid"`` URL writes to S3; any
        other value is treated as a local directory path.
    s3_options:
        Options forwarded to :class:`s3fs.S3FileSystem`.  Only used for S3
        targets; ignored (and optional) for local paths.  Never stored in
        the manifest.
    zarr_format:
        Zarr format version.
    encoding:
        Per-level encoding dictionaries.  Chunking always follows the
        dask chunks of the pyramid (first chunk along each dimension).
    write_coords:
        Whether to materialise the ``cell``/``latitude``/``longitude``
        coordinate arrays in the store.  HEALPix coordinates are a pure
        function of the cell index, and above roughly level 10 the
        arrays dwarf regional payloads (hundreds of GB at level 16, and
        they are never fill values, so chunk elision cannot help).
        ``"auto"`` (default) writes coordinates for levels up to
        :data:`WRITE_COORDS_MAX_LEVEL` and omits them above; ``True`` /
        ``False`` force either behaviour for all levels.  Coordinate-
        less stores keep the ``crs`` grid mapping, are marked as having
        implicit coordinates (see
        [`HealpixMetadata`][grid_doctor.metadata.HealpixMetadata]), and are
        meant to be accessed through the region selectors
        ([`select_bbox`][grid_doctor.select_bbox],
        [`select_cells`][grid_doctor.select_cells]), which reconstruct
        coordinates for exactly the cells they return.
    materialise:
        Data variables to compute and write completely during the init,
        e.g. small static fields.  They are not part of any task.
    structure:
        ``"flat"`` (default) writes one store per level,
        ``"<path>/level_<level>.zarr"``, and plans the fan-out tasks.
        ``"multiscales"`` writes the template of a single datatree store
        at *path* (one group per level) and returns ``None``: fan-out
        tasks are not supported for it yet, so *split*,
        *variables_per_task* and ``if_exists="resume"`` are rejected, and
        an existing store at *path* is overwritten.  Fill it with
        [`save_pyramid`][grid_doctor.save_pyramid] and
        ``structure="multiscales"``.
    split:
        Task size per dimension in index units, e.g. ``{"time": 24}``
        for tasks of 24 time steps.  Sizes are rounded **up** to a
        multiple of the zarr chunk (or shard) size along that dimension,
        taken over all variables and levels, so no two tasks ever write
        to the same chunk.  Several dimensions give the cartesian
        product of their regions.  Splitting along ``cell`` is not
        supported.  ``None`` (default) plans one task per group of
        variables, covering the whole store.
    variables_per_task:
        Maximum number of variables per task.  ``None`` (default) keeps
        all variables that share split dimensions and levels in one
        task, so the regridding they share is computed once per region.
    if_exists:
        What to do if *path* already has a manifest, level stores, or the
        remains of an interrupted init:

        - ``"error"`` (default): raise
          [`StoreExistsError`][grid_doctor.io.StoreExistsError].
        - ``"resume"``: if the stored manifest was planned exactly as
          this call would plan it (same path, levels, array layouts,
          split and tasks), return it unchanged, with its
          ``manifest_id``, and write nothing.  Tasks that already
          finished keep their markers, so re-submitting a conversion
          after a time-out only redoes the missing tasks.  Raises
          [`StoreExistsError`][grid_doctor.io.StoreExistsError] listing
          the differences otherwise, or if there is no readable
          manifest to resume (e.g. the previous init was killed).
          Without anything at *path* it initialises normally.
        - ``"overwrite"``: re-initialise.  All data is discarded, the
          result gets a new ``manifest_id``, and tasks and markers of the
          previous manifest become invalid; workers still running for
          it fail with ``StaleTaskError``.  Only overwrite when no
          worker of a previous run may still be writing: grid-doctor
          does not lock the store, and a worker that is already writing
          can put its data into the new stores before it notices.

    Returns
    -------
    PyramidManifest or None
        Store layout and tasks.  JSON-serialisable via
        ``manifest.to_json()`` and accepted directly as a reflow task
        result.  ``None`` for ``structure="multiscales"``.

    Examples
    --------
    ```python
    pyramid = create_healpix_pyramid(ds, max_level=9)
    manifest = init_pyramid_store(pyramid, "/scratch/out", split={"time": 24})
    for task in manifest.tasks:  # one array-job element each
        write_pyramid_task(pyramid, task)
    check_pyramid_store(manifest).raise_if_incomplete()
    ```
    """
    if if_exists not in ("error", "resume", "overwrite"):
        raise ValueError(f"if_exists must be 'error', 'resume' or 'overwrite', got {if_exists!r}")
    if structure not in ("flat", "multiscales"):
        raise ValueError(f"structure must be 'flat' or 'multiscales', got {structure!r}")
    materialise = list(materialise or [])
    if structure == "multiscales":
        unsupported = [
            name
            for name, given in (
                ("split", split is not None),
                ("variables_per_task", variables_per_task is not None),
                ("if_exists='resume'", if_exists == "resume"),
            )
            if given
        ]
        if unsupported:
            raise NotImplementedError(
                f"{', '.join(unsupported)} not supported for "
                "structure='multiscales' yet; use structure='flat' for fan-out "
                "writes"
            )
        _init_multiscales(
            pyramid,
            path,
            s3_options,
            zarr_format=zarr_format,
            encoding=encoding,
            write_coords=write_coords,
            materialise=materialise,
        )
        return None

    # Workers rebuild store paths from the manifest; keep them identical.
    path = path.rstrip("/")
    existing = inspect_target(path, s3_options, [f"level_{level}.zarr" for level in pyramid])
    if existing.exists and if_exists == "error":
        raise StoreExistsError(
            f"{path} already holds a pyramid ({existing.describe()}).  Pass "
            "if_exists='resume' to continue it or if_exists='overwrite' to "
            "start over."
        )
    if existing.exists and if_exists == "resume":
        if existing.manifest is None:
            raise StoreExistsError(
                f"cannot resume {path}: there is no readable manifest "
                f"({existing.describe()}).  Use if_exists='overwrite'."
            )
        templates = {
            level: maybe_drop_coordinates(ds, level, write_coords, WRITE_COORDS_MAX_LEVEL)
            for level, ds in pyramid.items()
        }
        return resume_init(
            existing.manifest,
            path,
            templates,
            {level: [str(k) for k in ds.data_vars if str(k) not in materialise] for level, ds in templates.items()},
            s3_options,
            zarr_format=zarr_format,
            split=split,
            variables_per_task=variables_per_task,
            materialised=[m for m in materialise if m in {str(v) for ds in pyramid.values() for v in ds}],
        )
    fs = get_filesystem(path, s3_options)
    begin_init(path, s3_options)
    level_specs: dict[int, LevelSpec] = {}
    for level, dataset in pyramid.items():
        template, combined_encoding = prepare_template(
            dataset,
            level,
            write_coords=write_coords,
            max_level_to_auto_write_coords=WRITE_COORDS_MAX_LEVEL,
            encoding=encoding,
            materialise=materialise,
        )
        task_vars = [str(k) for k in template.data_vars if str(k) not in materialise]
        store_name = f"level_{level}.zarr"
        root_path = f"{path}/{store_name}"
        store = get_store(root_path, fs)
        logger.info("Writing HEALPix to %s", root_path)
        zarr_options = get_zarr_options("w", zarr_format, combined_encoding)
        template.to_zarr(store, **zarr_options)  # type: ignore[call-overload]
        level_specs[level] = describe_level(
            level,
            store_name,
            store,
            template,
            task_vars,
            zarr_format=zarr_format,
        )

    unknown = sorted(set(materialise) - {str(v) for ds in pyramid.values() for v in ds})
    if unknown:
        logger.warning("materialise names unknown variables: %s", ", ".join(unknown))
    return finish_init(
        path,
        s3_options,
        [level_specs[lvl] for lvl in sorted(level_specs, reverse=True)],
        zarr_format=zarr_format,
        split=split,
        variables_per_task=variables_per_task,
        materialised=[m for m in materialise if m not in unknown],
    )

write_pyramid_task(pyramid, task, s3_options=None) ¶

Write one task's region of pyramid into an initialised store.

This is the function an array-job element calls. It is safe to run any number of tasks of the same manifest concurrently, on any number of nodes, without locks: the planner guarantees that no two tasks share a zarr chunk (or shard). Re-running a task overwrites the same region with the same data, so retries are harmless.

Parameters:

Name Type Description Default
pyramid Mapping[int, Dataset]

Mapping of level to dataset, built the same way as for the init step (same levels, variables, dimension lengths). It may cover either the full extent of the split dimensions, in which case the task region is selected here, or only the task region, e.g. because the source was subset with source.isel(task.isel()) before regridding. The second form is usually much cheaper, since only the task's slice of the source is read and regridded. Datasets may contain more variables or levels than the task needs; they are ignored.

 required
task WriteTask

The work unit, as taken from manifest.tasks.

 required
s3_options S3Options | None

Options for :class:s3fs.S3FileSystem. Credentials are never stored in the manifest, so every worker passes its own.

 None

Returns:

Type Description
WriteTask

task itself, after the data and the completion marker have been written. Returning the task (rather than nothing) makes the result usable as a cache key: reflow can check a cached result with verify=is_task_done.

Raises:

Type Description
StaleTaskError

The store was re-initialised after task was planned.
ManifestError

task is not identical to the task of the same id in the stored manifest (only tasks the manifest validated are written), or pyramid does not match the manifest (missing level or variable, different dimension lengths, a region the data cannot cover), or its coordinate values in the task region differ from the ones the init stored (e.g. another time range of the same length).

def write_pyramid_task(
    pyramid: Mapping[int, xr.Dataset],
    task: WriteTask,
    s3_options: S3Options | None = None,
) -> WriteTask:
    """Write one task's region of *pyramid* into an initialised store.

    This is the function an array-job element calls.  It is safe to run
    any number of tasks of the same manifest concurrently, on any number
    of nodes, without locks: the planner guarantees that no two tasks
    share a zarr chunk (or shard).  Re-running a task overwrites the
    same region with the same data, so retries are harmless.

    Parameters
    ----------
    pyramid:
        Mapping of level to dataset, built the same way as for the init
        step (same levels, variables, dimension lengths).  It may cover
        either the **full** extent of the split dimensions, in which case
        the task region is selected here, or **only the task region**,
        e.g. because the source was subset with
        ``source.isel(task.isel())`` before regridding.  The second form
        is usually much cheaper, since only the task's slice of the
        source is read and regridded.  Datasets may contain more
        variables or levels than the task needs; they are ignored.
    task:
        The work unit, as taken from ``manifest.tasks``.
    s3_options:
        Options for :class:`s3fs.S3FileSystem`.  Credentials are never
        stored in the manifest, so every worker passes its own.

    Returns
    -------
    WriteTask
        *task* itself, after the data and the completion marker have
        been written.  Returning the task (rather than nothing) makes
        the result usable as a cache key: reflow can check a cached
        result with ``verify=is_task_done``.

    Raises
    ------
    StaleTaskError
        The store was re-initialised after *task* was planned.
    ManifestError
        *task* is not identical to the task of the same id in the stored
        manifest (only tasks the manifest validated are written), or
        *pyramid* does not match the manifest (missing level or variable,
        different dimension lengths, a region the data cannot cover), or
        its coordinate values in the task region differ from the ones the
        init stored (e.g. another time range of the same length).
    """
    started = time.monotonic()
    target = _Target(task.path, s3_options)
    manifest = load_manifest(task.path, s3_options)
    if manifest.manifest_id != task.manifest_id:
        raise StaleTaskError(
            f"{task.task_id} belongs to manifest {task.manifest_id}, but "
            f"{task.path} was re-initialised with manifest "
            f"{manifest.manifest_id}; plan the tasks again from the new manifest"
        )
    try:
        planned = manifest.task(task.task_id)
    except KeyError:
        raise ManifestError(f"{task.task_id} is not part of manifest {manifest.manifest_id}") from None
    if planned != task:
        # The manifest validated that its own tasks are chunk-aligned and
        # disjoint; a task that differs (edited or hand-built) has no such
        # guarantee and could race with another worker.
        raise ManifestError(
            f"{task.task_id} differs from the task stored in the manifest "
            f"({task} != {planned}); use the tasks of the stored manifest"
        )

    writes: list[DeferredWrite] = []
    for level in task.levels:
        if level not in pyramid:
            raise ManifestError(
                f"{task.task_id} writes level {level}, but the pyramid only has levels {sorted(pyramid)}"
            )
        spec = manifest.level(level)
        store = target.store(spec.store)
        group = zarr.open_group(store, mode="r+", zarr_format=task.zarr_format)
        encodings = stored_encodings(store, zarr_format=task.zarr_format)
        for name in task.variables:
            array_spec = spec.array(name)
            if name not in pyramid[level]:
                raise ManifestError(f"{task.task_id}: variable {name!r} missing on level {level}")
            var = _select_region(pyramid[level][name].variable, array_spec, task)
            var = var.copy(deep=False)
            var.encoding = encodings.get(name, {})
            encoded = encode_zarr_variable(var, name=name, zarr_format=task.zarr_format)
            offsets = _region_offsets(array_spec, task)
            source = _aligned(encoded.data, array_spec.chunks, offsets, name)
            region = tuple(slice(off, off + n) for off, n in zip(offsets, encoded.shape))
            writes.append(DeferredWrite(source, get_array(group, name), region))

        mismatches = coordinate_differences(
            pyramid[level],
            store,
            spec.coords,
            zarr_format=task.zarr_format,
            region={dim: (start, stop) for dim, start, stop in task.region},
        )
        if mismatches:
            raise ManifestError(
                f"{task.task_id}: the pyramid does not match the coordinates "
                f"stored by the init on level {level} ("
                + "; ".join(mismatches)
                + ").  It was built from other data than the store; nothing "
                "was written."
            )

    store_all(writes)
    # The manifest was checked before writing.  If the store was
    # re-initialised meanwhile (an overwrite while this task ran), the
    # data above may have landed in the new stores: fail loudly instead
    # of reporting success, and never write a marker for it.
    if not is_current(task, s3_options):
        raise StaleTaskError(
            f"{task.path} was re-initialised while {task.task_id} was writing; "
            "its data may have been written into the new stores.  Do not "
            "re-initialise a store while a conversion into it is running."
        )
    marker = {
        "manifest_id": task.manifest_id,
        "task_id": task.task_id,
        "finished": datetime.now(UTC).isoformat(timespec="seconds"),
        "elapsed_s": round(time.monotonic() - started, 3),
        "host": socket.gethostname(),
        "variables": list(task.variables),
        "levels": list(task.levels),
        "region": {d: [a, b] for d, a, b in task.region},
    }
    target.write_text(json.dumps(marker, indent=2), STATE_DIR, DONE_DIR, f"{task.task_id}.json")
    logger.info(
        "%s done (%s, %d level(s)) in %.1fs",
        task.task_id,
        ", ".join(task.variables),
        len(task.levels),
        marker["elapsed_s"],
    )
    return task

def check_pyramid_store(
    manifest: PyramidManifest | str,
    s3_options: S3Options | None = None,
    *,
    inspect_chunks: bool = False,
) -> StoreReport:
    """Check whether a store is complete according to its manifest.

    The check is cheap: it reads the level metadata and lists one small
    marker file per finished task.  It does **not** read any data.

    A store is complete when

    1. the stored manifest is the one being checked (the store was not
       re-initialised in between),
    2. every level store and every array exists with the shape, write
       unit and dtype recorded in the manifest, and
    3. every task has written its completion marker.

    Parameters
    ----------
    manifest:
        The manifest returned by
        [`init_pyramid_store`][grid_doctor.init_pyramid_store],
        or the pyramid root path, in which case the stored manifest is
        loaded.
    s3_options:
        Options for :class:`s3fs.S3FileSystem` (S3 targets only).
    inspect_chunks:
        Also list the stored chunk keys and report, per finished task,
        how many chunks of its region are absent.  This lists every
        object of every array and can be slow on large S3 stores.  It
        never makes a store incomplete; see
        [`StoreReport.absent_chunks`][grid_doctor.StoreReport].

    Returns
    -------
    StoreReport
        Use ``report.complete`` (or ``bool(report)``),
        ``report.missing_tasks`` and ``report.summary()``; call
        ``report.raise_if_incomplete()`` to fail a workflow step.
    """
    if isinstance(manifest, str):
        manifest = load_manifest(manifest, s3_options)
    target = _Target(manifest.path, s3_options)
    problems: list[str] = []

    stored_text = target.read_text(STATE_DIR, MANIFEST_FILE)
    if stored_text is None:
        interrupted = _interrupted_init(target)
        problems.append(
            f"no manifest stored at {manifest.path}/{STATE_DIR}" + (f": {interrupted}" if interrupted else "")
        )
    else:
        stored_id = json.loads(stored_text).get("manifest_id")
        if stored_id != manifest.manifest_id:
            problems.append(f"store was re-initialised: it holds manifest {stored_id}, not {manifest.manifest_id}")

    groups: dict[int, zarr.Group] = {}
    for spec in manifest.levels:
        try:
            group = zarr.open_group(target.store(spec.store), mode="r", zarr_format=manifest.zarr_format)
        except Exception as error:  # noqa: BLE001 - report, do not raise
            problems.append(f"level {spec.level}: cannot open {spec.store}: {error}")
            continue
        groups[spec.level] = group
        members = set(group.array_keys())
        for name in spec.coords:
            if name not in members:
                problems.append(f"level {spec.level}: coordinate {name!r} missing")
        for array_spec in spec.data_vars:
            problems.extend(_check_array(spec.level, group, members, array_spec))

    known = {t.task_id for t in manifest.tasks}
    done: set[str] = set()
    stale = 0
    for filename in target.list_dir(STATE_DIR, DONE_DIR):
        if not filename.endswith(".json") or filename.startswith("."):
            continue
        text = target.read_text(STATE_DIR, DONE_DIR, filename)
        try:
            marker = json.loads(text or "")
        except json.JSONDecodeError:
            stale += 1
            continue
        task_id = marker.get("task_id")
        if marker.get("manifest_id") == manifest.manifest_id and task_id in known:
            done.add(str(task_id))
        else:
            stale += 1

    order = [t.task_id for t in manifest.tasks]
    done_tasks = tuple(t for t in order if t in done)
    missing = tuple(t for t in order if t not in done)

    absent: list[tuple[str, int, int]] = []
    if inspect_chunks:
        absent = _absent_chunks(manifest, target, groups, [manifest.task(t) for t in done_tasks])

    return StoreReport(
        manifest_id=manifest.manifest_id,
        n_tasks=len(manifest.tasks),
        done_tasks=done_tasks,
        missing_tasks=missing,
        problems=tuple(problems),
        stale_markers=stale,
        absent_chunks=tuple(absent),
    )

def __post_init__(self) -> None:
    """Validate and normalise the fields (lists become tuples)."""
    where = f"level {self.level!r}"
    coords = _str_tuple(self.coords, where, "coords", unique=True)
    data_vars = _instances(_as_tuple(self.data_vars, where, "data_vars"), ArraySpec, where, "data_vars")
    names = [spec.name for spec in data_vars]
    duplicates = sorted({n for n in names if names.count(n) > 1})
    if duplicates:
        _fail(where, f"duplicate data variables {duplicates}")
    both = sorted(set(names) & set(coords))
    if both:
        _fail(where, f"{both} listed as coordinate and data variable")
    _set(
        self,
        level=_as_int(self.level, where, "level", minimum=0),
        store=_as_str(self.store, where, "store", safe=True),
        coords=coords,
        data_vars=data_vars,
    )

def summary(self) -> str:
    """One human-readable paragraph."""
    state = "complete" if self.complete else "INCOMPLETE"
    lines = [(f"Store {state}: {len(self.done_tasks)}/{self.n_tasks} task(s) done (manifest {self.manifest_id}).")]
    if self.missing_tasks:
        shown = ", ".join(self.missing_tasks[:10])
        more = len(self.missing_tasks) - 10
        lines.append(f"Missing: {shown}" + (f" and {more} more." if more > 0 else "."))
    lines.extend(f"Problem: {p}" for p in self.problems)
    if self.stale_markers:
        lines.append(f"Ignored {self.stale_markers} stale marker(s).")
    if self.absent_chunks:
        absent = sum(a for _, a, _ in self.absent_chunks)
        lines.append(
            f"{absent} chunk(s) not stored in {len(self.absent_chunks)} finished "
            "task(s) (all-fill-value chunks are skipped by zarr; this is "
            "expected for masked or regional data)."
        )
    return "\n".join(lines)

def load_manifest(path: str, s3_options: S3Options | None = None) -> PyramidManifest:
    """Read the manifest that the init step stored below *path*.

    Parameters
    ----------
    path:
        Pyramid root, as passed to ``init_pyramid_store``.
    s3_options:
        Options for :class:`s3fs.S3FileSystem` (S3 targets only).

    Raises
    ------
    ManifestError
        If no manifest exists, e.g. because the init step has not
        finished or the store was not initialised with a manifest.
    """
    target = _Target(path, s3_options)
    text = target.read_text(STATE_DIR, MANIFEST_FILE)
    if text is None:
        interrupted = _interrupted_init(target)
        if interrupted:
            raise ManifestError(f"no manifest at {path}: {interrupted}")
        raise ManifestError(
            f"no manifest at {path}/{STATE_DIR}/{MANIFEST_FILE}: run "
            "init_pyramid_store first (or wait for it to finish)"
        )
    return PyramidManifest.from_json(text)

def is_current(item: PyramidManifest | WriteTask, s3_options: S3Options | None = None) -> bool:
    """Whether the store at ``item.path`` still holds ``item``'s manifest.

def is_task_done(task: WriteTask, s3_options: S3Options | None = None) -> bool:
    """Whether *task* has a completion marker for the current manifest.

    Equivalent to ``task.task_id in check_pyramid_store(...).done_tasks``
    but reads a single small file, so it is cheap enough to call per
    task, e.g. as reflow's ``verify=`` hook on the array job.

        The work unit.
    s3_options:
        Options for :class:`s3fs.S3FileSystem` (S3 targets only).

        return False
    text = _Target(task.path, s3_options).read_text(STATE_DIR, DONE_DIR, f"{task.task_id}.json")

    except json.JSONDecodeError:
        return False
    return bool(marker.get("manifest_id") == task.manifest_id and marker.get("task_id") == task.task_id)
