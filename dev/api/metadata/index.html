Metadata¶

Every attribute, coordinate name and grid mapping that grid-doctor stores is defined in grid_doctor.metadata. Code that produces data builds a HealpixMetadata and calls apply; code that reads data calls from_dataset. The stored layout follows the CF-1.13 healpix grid mapping; see Technical decisions for the full description.

from grid_doctor.metadata import HealpixGrid, HealpixMetadata, Provenance

meta = HealpixMetadata(HealpixGrid(level=8), Provenance(method="conservative"))
ds = meta.apply(ds)

HealpixMetadata.from_dataset(ds).grid.level  # 8

grid_doctor.metadata ¶

Metadata of grid-doctor datasets, written and read in one place.

Every attribute, coordinate name and grid mapping grid-doctor stores is defined in this package. Code that produces data builds a HealpixMetadata and calls apply; code that reads data calls HealpixMetadata.from_dataset. Changing the stored layout therefore never touches the write sites.

  • _grid: HealpixGrid, the grid itself (level, indexing scheme, figure of the earth).
  • _provenance: Provenance, how the values were produced.
  • _cf: the CF-1.13 healpix grid mapping spelling of a grid.
  • _dataset: HealpixMetadata, which combines the above and applies it to a dataset.
  • _multiscales: PyramidMetadata, the layout of a pyramid stored as one datatree, spelled with the Zarr multiscales and dggs conventions.
  • _pyramid: attributes of such a datatree's root group.
  • _keys: every stored name.

The written layout is CF-1.13: a scalar crs grid mapping variable (grid_mapping_name = "healpix", indexing_scheme, refinement_level), an integer cell index coordinate with standard_name = "healpix_index", and grid_mapping = "crs" on every variable along cell. xdggs.decode(ds, convention="cf") reads it. Pyramids written as one datatree additionally describe their levels on the root group (see PyramidMetadata).

def apply(self, ds: xr.Dataset) -> xr.Dataset:
    """Return *ds* with all grid-doctor metadata written.

    Writes

    - a scalar ``crs`` grid mapping coordinate (replacing any
      existing one),
    - CF attributes on the ``cell`` index coordinate and the
      ``latitude``/``longitude`` coordinates, where present,
    - ``grid_mapping = "crs"`` on every variable along ``cell``,
    - the global ``Conventions``, provenance and layout attributes.

    Global attributes owned by grid-doctor are rewritten from this
    object, so stale values copied from an input dataset never
    survive.  Coordinate *values* are left to the caller.

    Raises
    ------
    ValueError
        When the ``cell`` dimension or coordinate contradicts the
        grid or the layout.
    """
    self._check_layout(ds)
    crs = xr.DataArray(np.float64(0.0), attrs=grid_mapping_attrs(self.grid))
    # A shallow copy owns its attribute dicts, so *ds* is left untouched.
    result = ds.copy(deep=False).drop_vars(CRS_VAR, errors="ignore")
    result = result.assign_coords({CRS_VAR: crs})

    coord_attrs = ((CELL_DIM, INDEX_ATTRS), (LAT_VAR, LAT_ATTRS), (LON_VAR, LON_ATTRS))
    for coord, attrs in coord_attrs:
        if coord in result.coords:
            result[coord].attrs.update(attrs)

    for var in result.data_vars.values():
        if CELL_DIM in var.dims:
            var.attrs["grid_mapping"] = CRS_VAR

    global_attrs: dict[Hashable, object] = {
        key: value for key, value in result.attrs.items() if key not in OWNED_GLOBAL_ATTRS
    }
    global_attrs["Conventions"] = merge_conventions(ds.attrs.get("Conventions"))
    global_attrs[METADATA_VERSION_ATTR] = METADATA_VERSION
    global_attrs.update(self.provenance.to_attrs())
    if self.sparse:
        global_attrs[SPARSE_ATTR] = 1
    if self.implicit_coords:
        global_attrs[IMPLICIT_COORDS_ATTR] = 1
    result.attrs = global_attrs
    return result

def from_dataset(cls, ds: xr.Dataset) -> HealpixMetadata:
    """Read the metadata written by [`apply`][grid_doctor.metadata.HealpixMetadata.apply].

    Only the CF grid mapping is required, so CF HEALPix datasets

A HEALPix grid: refinement level, indexing scheme and figure of the earth.

Holds facts only; how they are spelled in a dataset is up to HealpixMetadata. Values are validated and normalised on construction, so a HealpixGrid is always a valid grid (NumPy integers from Zarr attributes are accepted and converted).

Parameters:

Refinement level (CF refinement_level), 0 to 29. nside = 2**level.

 required

earth_radius float | None

Radius of the spherical earth in metres, if it should be recorded. Only valid on a sphere.

 None
ellipsoid Ellipsoid

Ellipsoid the cell geometry is computed on, as a healpix_geo name: "sphere" (default) or "WGS84". Grids whose metadata records no ellipsoid, such as those written before it was recorded, are spherical.

 'sphere'

Examples:

>>> grid = HealpixGrid(level=3)
>>> grid.nside, grid.npix, grid.nest

npix property ¶

def __post_init__(self) -> None:
    """Validate and normalise the fields."""
    object.__setattr__(self, "level", _as_level(self.level))
    scheme = str(self.indexing_scheme)
    if scheme not in INDEXING_SCHEMES:
        raise ValueError(
            f"indexing_scheme must be one of {sorted(INDEXING_SCHEMES)}, not {self.indexing_scheme!r}."
        )
    object.__setattr__(self, "indexing_scheme", scheme)
    object.__setattr__(self, "earth_radius", _as_radius(self.earth_radius))
    object.__setattr__(self, "ellipsoid", _as_ellipsoid(self.ellipsoid))
    if self.earth_radius is not None and self.ellipsoid != "sphere":
        raise ValueError(
            f"earth_radius describes a sphere and cannot be combined with ellipsoid={self.ellipsoid!r}."
        )

def __post_init__(self) -> None:
    """Check that every ``derived_from`` points to a described level."""
    assets = {level.asset: level for level in self.levels}
    if len(assets) != len(self.levels):
        raise ValueError("Pyramid levels must have unique assets.")
    for level in self.levels:
        if level.derived_from is None:
            continue
        source = assets.get(level.derived_from)
        if source is None or source.grid is None or level.grid is None:
            raise ValueError(
                f"Level {level.asset!r} is derived from {level.derived_from!r}, "
                "which is not a HEALPix level of this pyramid."
            )
        if source.grid.level <= level.grid.level:
            raise ValueError(f"Level {level.asset!r} must be coarser than {level.derived_from!r}.")

def from_pyramid(cls, pyramid: Mapping[int, xr.Dataset]) -> PyramidMetadata:
    """Describe *pyramid* (``{level: dataset}``) from its levels' metadata.

    A level is derived from the level its provenance names in
    ``coarsened_from_level``, when that level is part of the
    pyramid.  Levels without HEALPix metadata are listed by path.
    """
    levels: list[PyramidLevel] = []
    for level in sorted(pyramid, reverse=True):
        ds = pyramid[level]
        asset = level_group(level)
        if not has_healpix_metadata(ds):
            levels.append(PyramidLevel(asset=asset, grid=None, coordinate=None))
            continue
        metadata = HealpixMetadata.from_dataset(ds)
        source = metadata.provenance.coarsened_from_level
        derived = source is not None and source != level and source in pyramid
        mode = metadata.provenance.coarsen_mode
        levels.append(
            PyramidLevel(
                asset=asset,
                grid=metadata.grid,
                coordinate=CELL_DIM if CELL_DIM in ds.variables else None,
                derived_from=(level_group(source) if derived and source is not None else None),
                resampling_method=(RESAMPLING_METHODS.get(mode, mode) if derived and mode else None),
            )
        )
    return cls(levels=tuple(levels))

def to_attrs(self) -> dict[str, object]:
    """Return the ``zarr_conventions`` and ``multiscales`` attributes."""
    assets = {level.asset: level for level in self.levels}
    methods = {level.resampling_method for level in self.levels if level.derived_from is not None}
    shared_method = methods.pop() if len(methods) == 1 else None

    layout: list[dict[str, object]] = []
    for level in self.levels:
        entry: dict[str, object] = {"asset": level.asset}
        if level.derived_from is not None and level.grid is not None:
            source = assets[level.derived_from]
            assert source.grid is not None  # checked in __post_init__
            entry["derived_from"] = level.derived_from
            entry["transform"] = {"scale": [float(2 ** (source.grid.level - level.grid.level))]}
            if level.resampling_method is not None and shared_method is None:
                entry["resampling_method"] = level.resampling_method
            entry["dggs"] = _changed_dggs(_dggs_object(source), _dggs_object(level))
        elif level.grid is not None:
            entry["dggs"] = _dggs_object(level)
        layout.append(entry)

    multiscales: dict[str, object] = {"layout": layout}
    if shared_method is not None:
        multiscales["resampling_method"] = shared_method
    conventions = [MULTISCALES_CONVENTION.to_dict()]
    if any(level.grid is not None for level in self.levels):
        conventions.append(DGGS_CONVENTION.to_dict())
    return {"zarr_conventions": conventions, "multiscales": multiscales}

@classmethod
def from_attrs(cls, attrs: Mapping[Hashable, object]) -> PyramidMetadata:
    """Read the layout written by [`to_attrs`][grid_doctor.metadata.PyramidMetadata.to_attrs].

    Raises
    ------
    ValueError
        When *attrs* have no ``multiscales`` layout or describe a
        grid other than HEALPix.
    """
    multiscales = attrs.get("multiscales")
    if not isinstance(multiscales, Mapping) or not isinstance(multiscales.get("layout"), list):
        raise ValueError("Attributes have no `multiscales` layout.")
    entries: dict[str, Mapping[str, object]] = {}
    for entry in multiscales["layout"]:
        if not isinstance(entry, Mapping) or not isinstance(entry.get("asset"), str):
            raise ValueError(f"Invalid multiscales layout entry: {entry!r}.")
        entries[entry["asset"]] = entry
    default_method = multiscales.get("resampling_method")

    resolved: dict[str, dict[str, object] | None] = {}

    def resolve(asset: str, seen: frozenset[str] = frozenset()) -> dict[str, object] | None:
        if asset in resolved:
            return resolved[asset]
        if asset in seen or asset not in entries:
            raise ValueError(f"Cannot resolve the dggs object of level {asset!r}.")
        entry = entries[asset]
        dggs = entry.get("dggs")
        source = entry.get("derived_from")
        if not isinstance(dggs, Mapping):
            result = None
        elif isinstance(source, str) and "name" not in dggs:
            base = resolve(source, seen | {asset})
            result = None if base is None else {**base, **dggs}
        else:
            result = dict(dggs)
        resolved[asset] = result
        return result

    levels = []
    for asset, entry in entries.items():
        dggs = resolve(asset)
        source = entry.get("derived_from")
        method = entry.get("resampling_method", default_method if source else None)
        levels.append(
            PyramidLevel(
                asset=asset,
                grid=None if dggs is None else _grid_from_dggs(dggs),
                coordinate=None if dggs is None else _optional_str(dggs.get("coordinate")),
                derived_from=source if isinstance(source, str) else None,
                resampling_method=_optional_str(method),
            )
        )
    return cls(levels=tuple(levels))

def grid_mapping_attrs(grid: HealpixGrid) -> dict[str, str | int | float]:
    """Return the attributes of the CF grid mapping variable for *grid*.

    ``refinement_level`` is always written: CF requires it for the
    ``nested`` and ``ring`` schemes, including level 0.
    """
    attrs: dict[str, str | int | float] = {
        "grid_mapping_name": GRID_MAPPING_NAME,
        "indexing_scheme": grid.indexing_scheme,
        "refinement_level": grid.level,
    }
    if grid.earth_radius is not None:
        attrs["earth_radius"] = grid.earth_radius
    if grid.ellipsoid == "WGS84":
        attrs["reference_ellipsoid_name"] = WGS84_CF_NAME
        attrs["semi_major_axis"] = WGS84_SEMI_MAJOR_AXIS
        attrs["inverse_flattening"] = WGS84_INVERSE_FLATTENING
    return attrs

def merge_conventions(existing: object) -> str:
    """Merge the CF version into an existing ``Conventions`` attribute.

    Any ``CF-x.y`` token is replaced by the version grid-doctor writes;
    other conventions (``CMIP-6.2``, ``ACDD-1.3``, ...) are kept in
    order.
    """
    tokens = str(existing).replace(",", " ").split() if existing else []
    kept = [token for token in tokens if not _CF_TOKEN.match(token)]
    return " ".join([CF_VERSION, *kept])
